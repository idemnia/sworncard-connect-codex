# SwornCard Connect для Codex

Плагин подключает Codex к облачному MCP SwornCard и добавляет инструкции для работы с паспортом агента. Пользователь может узнать, какие сервисы ему доступны, оформить паспорт и запросить баланс в Мостлайне при наличии прав.

## Установка

Источник каталога в менеджере плагинов Codex — `idemnia/sworncard-connect-codex`. Имя плагина — `sworncard-connect@sworncard-connect`. Установка добавляет MCP и skill. Для работы с личным подключением требуется PAT из кабинета Idemnia.

В этой версии MCP получает секрет из переменной среды процесса Codex `SWORNCARD_CONNECT_PAT`. Выпускайте PAT для выбранного подключения в личном кабинете Idemnia. Вставляйте его только в личную настройку клиента. Оставляйте чат, имя подключения и URL свободными от секретов.

После настройки откройте новый чат и напишите «Какие сервисы мне доступны через SwornCard?». Для проверки баланса напишите «Покажи мой баланс в Мостлайне». Если требуется оформление, завершите его по ссылке из ответа и повторите команду.

Адрес MCP RU — `https://connect.sworncard.ru/mcp`. Удаление плагина из Codex сохраняет подключение и паспорт. Для отключения доступа удалите подключение в кабинете Idemnia.
