# SwornCard Connect для Codex

Плагин добавляет в Codex облачный MCP SwornCard и инструкции по работе с паспортом агента. PAT для личного или рабочего подключения выдаёт кабинет Idemnia. Второе устройство может использовать сохранённый PAT того же подключения. Перевыпуск заменяет токен на всех устройствах этого подключения.

## macOS

Установите Codex Desktop в папку «Программы». В новом локальном чате напишите:

> Подключи SwornCard из https://github.com/idemnia/sworncard-connect-codex. Установи плагин sworncard-connect и открой его окно ввода PAT для macOS.

Если Codex запросит разрешение на установку или открытие окна, подтвердите действие. В системном диалоге «SwornCard · Подключение к Codex» проверьте адрес https://connect.sworncard.ru/mcp и вставьте PAT из Idemnia. Нажмите «Сохранить». Если плагин установлен и новый skill ещё недоступен в исходном чате, в новом локальном чате напишите «Подключи SwornCard». Установщику нужен доступ к личному профилю Codex.

Секрет хранится в личном файле настроек Codex на этом Mac. Файл должен быть доступен только владельцу. В чат передаётся только статус. Разные подключения получают отдельные записи. Повторите настройку для обновления PAT после его перевыпуска.

## Windows

В локальном Codex Desktop с установленным плагином напишите **«Подключи SwornCard»**. Если на чистом компьютере Codex не узнаёт название, укажите официальный источник:

> Подключи SwornCard из https://github.com/idemnia/sworncard-connect-codex. Установи плагин и открой его окно ввода PAT для Windows.

Для обновления ранее установленной версии напишите: «Обнови плагин SwornCard из https://github.com/idemnia/sworncard-connect-codex и открой окно ввода PAT для Windows». Если старый каталог закреплён за прежним тегом, менеджеру потребуется заменить регистрацию каталога SwornCard и установить новую версию пакета. Существующее подключение в Idemnia используется повторно.

Разрешите открыть окно, если Codex запросит подтверждение. В окне **SwornCard · Подключение к Codex** проверьте адрес `https://connect.sworncard.ru/mcp`, вставьте PAT из кабинета Idemnia, нажмите **Сохранить**, затем **Готово**. Для каждого подключения окно сохраняет PAT в Диспетчере учётных данных текущего пользователя Windows. В личных настройках Codex остаются адрес сервера и команда получения авторизации. Песочнице достаточно обычных прав чтения настроек. Доступ к записи Диспетчера учётных данных принадлежит пользователю Windows. Плагин также проверяет контекст процесса Codex перед передачей авторизации. После перевыпуска токена повторите те же действия.

В чате напишите **«Какие сервисы мне доступны через SwornCard?»**. Если клиент ещё показывает прежний список инструментов, полностью закройте Codex Desktop, запустите его снова и повторите вопрос в новом локальном чате. Для WSL и удалённых сессий настройку выполняют на том хосте, где работает MCP-клиент; это окно предназначено для нативного Windows Desktop.

В автоматической проверке Windows открывается окно официального Desktop с сохранённой настройкой. Отдельный запуск его движка подтверждает доступ к изолированному тестовому каталогу. Ответ в чате с вашим аккаунтом проверяется приведённым выше вопросом.

## Проверка и отключение

В новом чате напишите «Какие сервисы мне доступны через SwornCard?». При действующем паспорте и правах можно запросить «Покажи мой баланс в Мостлайне». Если требуется оформление, завершите его по ссылке из ответа и повторите запрос.

Локальную запись токена в Windows можно удалить в «Диспетчер учётных данных → Учётные данные Windows → Общие учётные данные» по имени SwornCard Connect и идентификатору подключения.

Удаление плагина сохраняет паспорт и созданную на Mac или Windows персональную запись MCP. При необходимости удалите эту запись в личных настройках MCP клиента. Для прекращения доступа на всех устройствах удалите подключение в кабинете Idemnia.
